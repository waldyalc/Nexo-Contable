# Skill: Pedir Ayuda

1. Si un problema persiste tras 2 intentos distintos de diagnóstico, detente y reporta claramente: qué intentaste, el error exacto y las opciones concretas.
2. No improvises cambios fuera del alcance asignado ni desactives candados/tests para "hacerlo pasar".
